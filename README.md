# DailyMate AI v1.0 starter
Mobile-friendly Progressive Web App (PWA), not an Android APK.

Included: message templates, English/Arabic/Urdu/Hindi phrasebook, local notes with edit/delete, percentage/discount/bill-split calculator, daily checklist and tips.

## Publish
Upload and replace `index.html`, `app.js`, `manifest.webmanifest`, `sw.js`, and `README.md` in the ROOT of your existing GitHub repository. Commit changes, wait for the green Actions tick, then open the site.

## Honest limitations
- Message Writer uses templates; it is not connected to a real AI model.
- Language Helper is a phrasebook, not a general translator.
- Most interface labels remain English; selecting Arabic/Urdu changes direction and tagline only.
- Notes stay in this browser on this device. Clearing site data can erase them.
- No ads, premium billing, account sync, cloud backup, or Google Play APK is included.
- Real AI needs a secure backend. Never publish a private API key in `app.js` or GitHub Pages.
