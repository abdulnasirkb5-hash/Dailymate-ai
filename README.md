# DailyMate AI – Version 0.3

A mobile-friendly progressive web app starter with offline-friendly tools.

## Included
- Message/email draft template
- Predefined phrase examples in English, Arabic, Urdu and Hindi
- CV profile builder
- Social caption ideas
- Percentage, discount and bill-split calculator
- Smart Notes with local-device saving and visible saved-note preview

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of a GitHub repository.
2. In Settings → Pages, select Deploy from a branch, `main`, and `/ (root)`.
3. Wait for the Pages deployment to finish.

## Notes
- Smart Notes uses browser localStorage on the current device and browser. It does not sync between devices or browsers.
- AI generation, full sentence translation, accounts, advertisements and subscriptions are not connected in this starter.
- Do not store sensitive information in this demo.
